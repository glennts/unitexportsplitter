Manual import guide

For manual import, first create the user in the portal.
  1. Add units to the portal
    Log in as Superuser → Device page → Registrer via CSV — upload telespornr.csv
  2. Impersonate the user
    Enhetsliste → Tilknytt via CSV — upload telespornr.csv
  3. Upload the individuals
    Individliste → Last opp individer — upload individualnr.csv
